# 🤖 Фриланс-платформа в Telegram

Полнофункциональный бот для фриланс-площадки с двумя ролями: Заказчик и Исполнитель.

## 📋 Возможности

- **Заказчики**: создание заданий (ТЗ) с оплатой 100 ₽ за публикацию
- **Исполнители**: подписка на категории, получение уведомлений о новых заданиях
- **Резюме**: публикация резюме за 100 ₽ (активно 3 месяца)
- **Реферальная программа**: +24 часа подписки за каждого приглашённого друга
- **Автоархивация**: задания и резюме архивируются через 3 месяца
- **Админ-панель**: статистика, управление пользователями, рассылка

## 💰 Монетизация

|--------|------|

## 🚀 Установка и запуск

### 1. Клонирование и настройка

```bash
git clone <repo-url>
cd freelance_bot
cp .env.example .env
```

Отредактируйте `.env`:
- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_IDS` — ваш Telegram ID
- `PAYMENT_PROVIDER_TOKEN` — токен платёжной системы

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка каналов

В `config.py` укажите Telegram-каналы для каждой категории:
```python
CATEGORY_CHANNELS = {
    "Веб-дизайн": "@vakansii_design",
    "Копирайтинг": "@vakansii_copy",
    # ...
}
```

Бот должен быть администратором в каждом канале.

### 4. Запуск

```bash
python main.py
```

## 🗄 База данных

Бот использует SQLite с таблицами:
- `users` — пользователи и роли
- `subscriptions` — подписки исполнителей
- `categories` — категории заданий
- `user_categories` — выбранные категории исполнителей
- `tasks` — задания заказчиков
- `resumes` — резюме исполнителей
- `payments` — история платежей
- `referrals` — реферальные связи

## ⚠️ Важные замечания

1. **Telegram Payments**: для приёма платежей нужен токен от @BotFather (Settings → Payments)
2. **Каналы**: бот должен быть администратором в каждом канале категории
3. **Публикация в каналы**: в текущей версии публикация в каналы требует доработки (нужно добавить логику отправки в `successful_payment`)
4. **Безопасность**: используйте PostgreSQL в продакшене вместо SQLite
5. **Webhook**: для продакшена настройте webhook вместо polling
